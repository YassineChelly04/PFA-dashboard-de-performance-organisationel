# Requirements — PFA Tunisie Telecom

## Problem statement

Tunisie Telecom needs an internal application to support the management of customer complaints within the complaints center. The process is critical because it directly affects customer satisfaction and operational performance.

## Project objective

Build a web application that helps responsible users:

- Track complaint processing activity,
- Detect dysfunctions and deviations from targets,
- Support continuous improvement with real operational data.

## Functional objectives

- Capture complaint records,
- Track complaint status,
- Trigger alerts when thresholds are exceeded,
- Analyze complaint causes using Pareto analysis,
- Support deviation analysis and improvement actions.

## Data-driven goals

- Use dynamic data coming from the operational interfaces,
- Keep KPI values traceable to a formula and source,
- Support updates from supplier and Tunisie Telecom agent interactions.
