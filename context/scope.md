# Scope — PFA Tunisie Telecom

## In scope

- Interface Fournisseur
- Interface Agent Tunisie Telecom
- Complaint entry and update flows
- Status tracking: open / in progress / closed
- Operational alerts
- Pareto analysis support
- KPI calculations for the complaint process

## Out of scope for this phase

- Dashboard de performance organisationnelle
- Broader enterprise reporting beyond the complaints center
- Features not directly tied to the supplier or agent interfaces

## Scope note

The dashboard may be considered later, but it is explicitly excluded from the current development phase.
