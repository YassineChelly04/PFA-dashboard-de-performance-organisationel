# KPI Specification — PFA Tunisie Telecom

## KPI axes

| Axis | Example KPIs |
|---|---|
| Client | Satisfaction rate, processing delay |
| Process internal | Number of complaints, handling rate |
| Quality | Error rate, procedure compliance |
| Financial | Average cost per complaint, cost of poor quality |
| Human resources | Cases per agent, absenteeism rate |

## KPI rules

Each KPI should include:

- A clear formula,
- An interpretation,
- A source of truth,
- A refresh/update rule if needed.

## Reporting needs

- KPIs must reflect live or near-live operational changes from the two interfaces.
- KPI definitions should be stable enough to support Pareto analysis and improvement tracking.
