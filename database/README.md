# Data

`all-data.xlsx` is a **synthetic** dataset of 22,000 technical interventions, generated by `generate_synthetic_data.py`. It keeps the columns, formats and overall shape of the original operational records (regions, offers, fault types, resolution codes, durations) so the three apps and the dashboard behave the same, but no row describes a real customer line or intervention.

Regenerate it (and copy it into each app's `data/` folder):

```bash
pip install pandas numpy openpyxl
python database/generate_synthetic_data.py --rows 22000 --seed 2026
```
